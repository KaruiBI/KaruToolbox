# Karui 智能创作工作台：产品路线图

## 1. 产品定位

Karui 的差异化不是比专业 NLE 拥有更多按钮，而是把以下能力合在一个清晰工作流里：

- 像轻量剪辑软件一样快速完成片段、音频、字幕和导出；
- 像专业软件一样拥有工程、轨道、代理、可撤销编辑和可靠渲染；
- 像 AI 工作台一样理解参考图、脚本、品牌风格和用户历史；
- 像本地工具一样尊重隐私、离线可用、文件不必上传；
- 本地算力不足时，用户可以主动切换到自己配置的远程服务。

建议将新模块在产品内称为“Karui 创作台”或“Karui Studio”，它属于 Karui 工具箱，不需要另起一套品牌。

## 2. 主流软件带来的产品基线

这些不是照抄清单，而是用户对现代视频软件的基本预期：

- DaVinci Resolve 的编辑页以多轨、拖拽、修剪、代理、关键帧、字幕和素材管理为核心；字幕本身就是时间线轨道，可导入、编辑、烧录或单独导出。[Blackmagic Design 产品页](https://www.blackmagicdesign.com/products/davinciresolve)、[字幕与标记说明](https://www.blackmagicdesign.com/ca/products/davinciresolve/edit)
- Premiere 的文本编辑可以把转录文本和时间线同步，删除或重排文字会形成粗剪；自动转录还支持语言、说话人和指定轨道。[Adobe 文本编辑](https://helpx.adobe.com/premiere/desktop/edit-projects/edit-video-using-text-based-editing/overview-of-text-based-editing.html)、[Adobe 自动转录](https://helpx.adobe.com/premiere/desktop/add-text-images/insert-captions/auto-transcribe-video-using-speech-to-text.html)
- CapCut 把自动字幕、字幕样式、关键帧、画幅适配和快速导出做成低门槛工作流。[CapCut 自动字幕](https://www.capcut.com/help/how-to-recognise-subtitles)、[CapCut 关键帧](https://www.capcut.com/resource/how-to-add-keyframes-in-capcut)
- OpenTimelineIO 证明了“工程编辑信息”和“媒体文件”应分离；时间线需要 clip、track、transition、marker、metadata 和版本化 schema。[OpenTimelineIO 概览](https://opentimelineio.readthedocs.io/en/latest/)
- FFmpeg 已提供 concat demuxer/filter、overlay、drawtext、subtitles 和复杂 filter graph，可作为 Karui 第一阶段可靠渲染后端。[FFmpeg 拼接说明](https://ffmpeg.org/faq.html)、[FFmpeg Filters](https://www.ffmpeg.org/ffmpeg-filters.html)

## 3. 目标用户流程

### 3.1 普通剪辑

1. 新建工程，选择横屏/竖屏和分辨率。
2. 导入多个视频、图片和音频。
3. 素材自动探测时长、分辨率、帧率、编码和音轨。
4. 拖入时间线，完成排序、裁剪、分割、转场、音量和字幕。
5. 预览并导出 MP4；下次打开仍能恢复工程。

### 3.2 智能粗剪

1. 导入采访、课程或口播。
2. 本地转录，生成带时间码和说话人的文本。
3. 用户通过删除文字、标记保留段落生成粗剪建议。
4. AI 只生成编辑命令预览；用户确认后写入时间线。
5. 自动生成字幕轨，并允许统一调整样式。

### 3.3 参考图修图

1. 用户导入参考图和待修改图。
2. 选择修图目标：局部重绘、扩图、换背景、风格参考、清晰放大、颜色匹配。
3. 局部重绘时在 Karui 中画遮罩。
4. Karui 将原图、参考图、遮罩上传到已配置的本地/远程 ComfyUI，再提交受控工作流。
5. 每次结果都作为新版本保存，原图永不覆盖；用户可以对比、回退或加入素材库。

### 3.4 用户记忆

1. 用户明确告诉 Karui：“以后竖屏默认 1080×1920”“字幕用白字蓝色关键词”“我的品牌色是这些”。
2. 系统保存为可查看的结构化记忆，并显示来源与适用范围。
3. 新工程创建时提出建议，不擅自覆盖项目设置。
4. 用户可以导出 `.karuimemory`，在另一台设备导入；导入前预览差异。

## 4. 功能版图

### 4.1 专业剪辑基础（P0）

- 工程新建、打开、另存、自动保存和崩溃恢复；
- 素材库、缩略图、代理状态、缺失媒体重新链接；
- 视频/音频/图片/文字/字幕轨；
- 片段添加、移动、排序、分割、裁剪、删除、复制；
- 吸附、播放头、缩放时间线、帧级步进；
- 撤销/重做；
- 多片段统一规格后合并导出；
- 导出预设、进度、取消、失败日志和结果定位。

### 4.2 音频与字幕（P0/P1）

- 波形缓存；
- 音量、静音、淡入淡出、声道选择；
- 背景音乐和人声分轨；
- 响度标准化与简单 ducking；
- SRT/VTT 导入、编辑和导出；
- 字幕轨样式、位置、描边、背景和烧录；
- 本地自动转录；
- 后续增加说话人识别、去口头禅和文字粗剪。

### 4.3 画面编辑（P1）

- 缩放、位置、旋转、不透明度、裁剪、圆角；
- 关键帧；
- 基础转场；
- LUT/亮度/对比度/饱和度/色温；
- 画幅适配、模糊背景和智能重构图；
- 贴纸、文字模板和品牌模板。

### 4.4 AI 创作（P1/P2）

- 参考图上传与版本链；
- inpaint/outpaint/upscale/background remove/style reference；
- 文生图、图生图、文生视频、图生视频；
- 脚本拆镜、镜头建议、B-roll 建议；
- 基于转录的粗剪建议；
- 自动字幕、标题、摘要、封面和多平台文案；
- 工程级 AI 助手：任何修改都先生成可撤销命令和差异预览。

### 4.5 Skill 系统（P2）

Skill 是可复用能力，不等同于一个按钮。示例：

- “口播短视频”：转录 → 去停顿 → 字幕 → BGM ducking → 9:16 导出；
- “参考图商品修图”：分割主体 → 换背景 → 色彩匹配 → 放大 → 导出；
- “采访精剪”：说话人识别 → 文本选段 → 多机位同步 → 字幕；
- “多平台发布”：从一个工程导出 16:9、9:16、1:1，并套用不同安全区。

如果产品所有者说的“SK 技能”实际是“快捷键”，专业剪辑快捷键也应作为 P0：空格播放/暂停、J/K/L、I/O 入出点、Ctrl+K 分割、Delete 波纹删除、Ctrl+Z/Y、方向键逐帧、`+/-` 缩放时间线，并允许用户自定义。

## 5. 分阶段路线

### Phase 0：稳定底座（必须先做）

目标：停止继续扩大单体文件，让后续功能有地方生长。

- 新增独立 `src/features/editor/`，不再往 `main.js` 添加编辑器逻辑；
- 定义 Karui Project v1 schema；
- 定义统一 Job 状态和事件；
- Rust command 按 `media/project/render/memory/ai` 拆模块；
- 建立最小测试和 fixture；
- 保持现有工具行为不变。

完成标志：能创建一个空工程、保存、关闭、重新打开，数据完全一致。

### Phase 1：可用的视频工程 MVP

目标：真正完成“多个片段 + 音频 + 字幕”的闭环。

- 素材导入和探测；
- 单视频轨 + 两音频轨 + 一字幕轨；
- 排序、裁剪、分割、删除、音量；
- SRT 导入/编辑；
- 项目预览；
- FFmpeg 合并导出；
- 自动保存和撤销/重做。

完成标志：用户能导入三个不同规格视频、一首 BGM 和一个 SRT，完成剪辑并稳定导出一个同步正确的 MP4。

### Phase 2：智能字幕与快速剪辑

目标：达到现代内容创作者的基础效率。

- 本地 Whisper provider；
- 逐句/逐词时间码；
- 字幕样式模板；
- 静音检测、去空白建议；
- 文本选择生成粗剪；
- 代理媒体和波形缓存。

本地字幕引擎可评估 whisper.cpp；它提供可下载的 GGML 模型和本地 CLI，适合离线产品，但模型下载、许可证和硬件回退必须单独设计。[whisper.cpp 模型说明](https://github.com/ggml-org/whisper.cpp/blob/master/models/README.md)

完成标志：一段 20 分钟中文口播可离线转录、形成字幕轨，并通过文本删除生成可撤销粗剪。

### Phase 3：参考图与 AI 修图

目标：让 Karui AI Studio 从纯生成变成实际生产工具。

- 素材上传接口；
- 遮罩编辑器；
- 图生图/inpaint/outpaint/upscale 预设工作流；
- 参考图/结果图版本关系；
- 本地与远程 provider 一致的任务状态；
- 失败诊断和模型缺失提示。

完成标志：用户选择一张原图、一张参考图和一个遮罩区域，可以生成多个不覆盖原图的版本并拖入视频工程。

### Phase 4：记忆与 Skill

目标：形成 Karui 自己的产品护城河。

- SQLite 记忆数据库；
- 记忆查看、编辑、删除、导出和导入；
- 品牌档案、默认参数和参考素材；
- Skill manifest、执行计划、权限与日志；
- 用户确认过的多步骤 Skill；
- 工程助手和差异预览。

完成标志：用户导出记忆包，在另一设备导入后，新工程能正确建议其字幕和品牌设置；导出包不含任何密钥。

### Phase 5：专业化与生态

- 多视频轨、嵌套序列、多机位；
- 更完善关键帧、蒙版和跟踪；
- OTIO/EDL/FCPXML 导入导出；
- 可安装 Skill 市场；
- 团队模板与可选云同步；
- 性能分析、GPU 编码、智能代理。

## 6. 暂时不做

- 不在 MVP 做完整节点合成器、三维、粒子和高级调色；
- 不做多人实时协作；
- 不做自建大规模模型云；
- 不允许 Skill 任意运行 PowerShell/Python；
- 不承诺所有 Premiere/Resolve 工程可无损互转；
- 不把用户文件默认上传到任何服务。

## 7. 产品成功指标

- 首次用户 10 分钟内完成首个多片段导出；
- 工程自动保存后恢复成功率 > 99.9%；
- 取消渲染后 3 秒内停止子进程并清理临时文件；
- 常见 1080p 工程的时间线交互保持流畅；
- AI 操作 100% 可追踪来源、可撤销、可比较结果；
- 记忆 100% 可查看/删除/导出，导出包 0 密钥；
- 每个新功能都有空态、错误态和中断恢复，不以“成功路径能跑”为完成。
