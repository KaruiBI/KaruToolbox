## T017：内置 ComfyUI 运行时与统一 AI 目录

状态：**核心链路已实现，等待离线打包与真实设备验收（2026-09-30）**

### 目标

让用户不需要单独下载、安装、启动或选择 ComfyUI 文件夹，同时保证引擎升级不会覆盖模型和用户数据。

### 首版范围

- `AI/runtime` 与 `AI/data` 分离；
- 运行时 manifest、版本、SHA-256、许可证和来源；
- 内置运行时安装、校验、启动、停止、回滚和日志；
- 统一模型目录和现有下载器迁移；
- 本地模型包导入；
- 外部本地/远程 ComfyUI 保留为高级模式。

### 已完成

- 内置运行时在线安装、本地压缩包/解压目录导入、校验、启动、停止和回滚；
- `AI/runtime` 与 `AI/data` 分离，下载器默认写入统一模型目录；
- 安装和启动时生成 `extra_model_paths.yaml`，让内置 ComfyUI 访问统一模型目录；
- 模型程序内下载、手动导入、打开实际目录及旧 ComfyUI 模型库关联；
- 内置模式不再要求用户选择含 `main.py` 的外部目录；
- 退出程序时清理受管引擎、下载任务与 AI 连接。

### 剩余

- 将固定运行时正式打入 AI 离线安装资源并完成签名、升级测试；
- 在全新 NVIDIA 机器完成离线安装和图片生成闭环；
- 完成中文/空格/非系统盘、回滚和断电恢复测试；
- 补齐全部模型、节点的固定版本、checksum 和许可证清单。

### 验收

- 全新 Windows 电脑安装 AI 离线版后无需外部 ComfyUI；
- 能离线启动引擎并生成测试图片；
- 更新运行时不移动或删除模型；
- 退出 Karui 后不保留受管推理进程和下载连接；
- 中文路径、空格路径和非系统盘存储均通过验证。

## T002：工程保存、打开、自动保存和迁移

### 目标

通过 Rust command 安全读写 `.karuiproject`。

### 要求

- 原子保存：写临时文件、fsync/close、替换正式文件；
- 最近一次自动保存单独存放，不覆盖用户手动保存；
- 打开时校验 schemaVersion；
- 保存失败不修改 dirty 状态；
- 路径含中文/空格可用；
- 记录最近项目只保存路径和展示信息。

### 验收

- 新建 → 保存 → 修改 → 自动保存 → 模拟退出 → 恢复成功；
- 写入中断不会破坏旧工程；
- 无权限路径有中文可理解错误；
- 旧 schema fixture 可迁移。

## T004：统一媒体探测服务

**状态：2026-09-24 已完成首版。** Rust 已提供结构化 `probe_media`，编辑器导入后会自动分析并展示核心参数；无音轨、VFR 和手机旋转视频的二进制回归 fixture 仍需后续补齐。

### 目标

把现有 `probe_video` 扩展为稳定的 `probe_media`。

### 输出

- container、duration、size；
- video streams：codec、width、height、fps rational、rotation、pixFmt、color；
- audio streams：codec、sampleRate、channels、layout、language；
- subtitle streams；
- 文件 fingerprint；
- 结构化错误。

### 验收

- MP4/MOV/MKV/MP3/WAV/JPG/PNG 可探测；
- 无音轨、可变帧率、手机旋转视频有 fixture；
- ffprobe 输出异常不会 panic；
- 前端不解析原始 ffprobe JSON。
