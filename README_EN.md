# Karui Toolbox

Karui Toolbox is a local desktop utility suite for PDF, image, audio, video, text, calculator, creative, and AI-assisted workflows.

## Development

```powershell
cd toolknit-desktop
npm install
npm run dev
```

The default local address is `http://127.0.0.1:1420`.

The desktop build requires Node.js 20+, Rust stable, and `ffmpeg.exe` at `toolknit-desktop/src-tauri/resources/ffmpeg/ffmpeg.exe`.
